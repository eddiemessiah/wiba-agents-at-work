01 · The only definition you need

A script obeys. An agent decides — and it holds a wallet.

A script
  • Does exactly what you typed
  • Stops the moment reality differs
  • Cannot decide anything
  • Has no money
An agent
  • Gets an outcome, works out the steps
  • Reads, retries, asks when stuck
  • Holds its own wallet
  • Can pay, and can get paid
You have already used the first half. The wallet is the new part — and it is the entire reason this hackathon exists.
